# Decision 0003: Use a senior-analyst workpaper visual system

Date: 2026-08-17

Status: accepted; current responsive evidence approved for publication on 2026-08-18

## Context

The existing workbench has strong decision logic, but its rounded cards, decorative brand mark, equal-weight metric tiles, question-style headings, and long explanatory passages read like a generic generated dashboard. The intended user is an experienced policy analyst preparing a governed review.

## Decision

Use a risk-control workpaper as the product's visual and language model. Add a compact review register, show the active page heading, replace card hierarchy with ruled sections and schedules, use direct exception language, and expose owner, evidence period, status, and use boundary before the first exhibit.

Keep the existing React and CSS stack. Do not add a component library, animation system, icon package, or new data dependency. Preserve all current controls, analytical calculations, evidence boundaries, responsive states, and accessibility behavior.

## Why

An experienced policy analyst needs a dated review, a controlling exception, traceable evidence, and a next action. The workpaper model supports that task directly and does not imply a live operating system.

## Alternatives rejected

- A black terminal or market-data treatment, because it signals novelty and live operations the retrospective source does not support.
- A slide-deck layout, because the primary task is testing and recording a decision rather than presenting a fixed conclusion.
- A component-library rewrite, because the existing native controls and shared primitives already support the workflow.

## Not done

No component library, animation system, icon package, data dependency, model, threshold, or analytical result was changed. Approval was recorded only after the owner requested the preview and directed publication of the complete product on 2026-08-18.

## Changed

The shell, hierarchy, section treatment, metric register, band selector, control sizing, headings, and responsive evidence now follow the senior-analyst workpaper contract.

## Consequences

The product is denser, quieter, and more explicit about review status. Screenshots were regenerated at 1440px and 390px for every view and risk schedule, passed the finish review, and are covered by the 2026-08-18 publication directive. Earlier design approval did not carry forward after this visual change.

The workpaper language does not turn the source into fraud evidence. First-EMI default remains a credit-risk outcome with possible operational contamination.
